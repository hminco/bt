03

핵심 지표 정의

기간에 따라 DAU·WAU·MAU 계산 방식이 다릅니다.

GA4 API 수집 데이터 안내

GA4는 자체적으로 샘플링과 모델링을 적용하고, API의 “필터” 방식과 GA4 화면의 “세그먼트” 방식은 사용자 계산 시 미묘한 차이가 있어 완전한 오차 제로는 어렵습니다.

0.1~0.3%활성사용자 · 조회수2~4%신규사용자 · 재방문자
리포트DAUWAUMAU
주간7일간 일별 활성사용자수 평균7일 전체 활성사용자수주 종료일 기준 28일 롤링 활성사용자
월간해당 달 일별 활성사용자수 평균각 주(yearWeek) 활성사용자수 평균해당 달 전체 활성사용자수
주간 MAU(28일 롤링)와 월간 MAU(달력월 전체)는 계산 방식이 다르므로 직접 비교하지 않습니다.

인사이트 판정 기준

08

알려진 한계

해석 시 아래 사항을 함께 고려합니다.

  • 페이지별 리포트는 PC만 집계하며 모바일 페이지별 리포트는 별도로 구축하지 않습니다.
  • 이탈률과 페이지별 평균참여시간은 근사치이며 GA4 UI의 정밀한 페이지 단위 지표와 정확히 일치하지 않을 수 있습니다.
  • 월간 WAU 계산 시 첫 주와 마지막 주가 다른 달과 겹쳐 7일 미만으로 집계될 수 있습니다.
  • 신규사용자와 재방문자는 GA4 탐색 화면의 세그먼트 방식과 API 필터 방식 사이에 0.1~2% 수준의 미세한 오차가 있을 수 있습니다.
