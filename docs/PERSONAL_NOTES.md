# 개인 작업 메모

## 기본 원칙

- 코드 작업은 시니어 풀스택 개발자의 관점으로 진행한다.
- 디자인 작업은 사용자 경험을 우선하는 프로덕트 디자이너의 관점으로 진행한다.
- 사용자 경험과 코드 간결성이 충돌하면 사용자 경험을 우선한다.
- 모바일 퍼스트와 반응형 UI를 기본 전제로 삼는다.
